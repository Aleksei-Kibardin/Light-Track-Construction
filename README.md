# Vue 3 + TypeScript + Vite

Track Configurator

**Демо:** https://glittering-naiad-7c3e4a.netlify.app/

Конфигуратор трековых систем освещения на Vue 3 + Three.js.
Тестовое задание: сделать концепт визуального конструктора, где пользователь меняет параметры трека и видит результат.

Что умеет:

3D-предпросмотр: трек, светильники, свет, тени.
4 формы трека: линия, угол, U-тип, прямоугольник.
Общая длина от 1 до 5 м.
Длины сторон A/B — визуальные, на модель пока не влияют.
3 покрытия: чёрный, белый, графит.
Светильники: выбор модели, количество от 1 до 8, перетаскивание по треку.
Температура света от 2700 K до 5000 K.
Удаление светильника: кнопка появляется при наведении.
Смета: список комплектующих с моковыми вторичными позициями (блок питания, коннекторы, монтаж).
Камера: вращение, зум, перенос модели.

Стек

Vue 3 + TypeScript
Vite
Three.js
Tailwind CSS v4
Composition API

Запуск

npm install
npm run dev

Открыть http://localhost:5173

Сборка:

npm run build
npm run preview

Управление

Зажать светильник — перетаскивание вдоль трека.
Зажать трек — перемещение модели по плоскости.
Зажать фон — вращение камеры.
Scroll — зум.
Hover на светильнике — появляется кнопка удаления.


Что сделано специально

Моки. Смета, модели светильников, цены — заглушки.
Позиции светильников живут в TrackScene, а не в Vue: так drag не конфликтует с реактивностью.
Без стейт-менеджера, в виду избыточности, можно было бы сделать для имитации реального проекта, но я решил что не стоит.
